# Cashier Cash Counter

A mobile-friendly Progressive Web App for Philippine peso cash counting.

## Features
- Two-way quantity / total calculation for ₱1, ₱5, ₱20, ₱50, ₱100, ₱200, ₱500 and ₱1,000
- Loose coins and optional other cash adjustment
- Separate PCV Loose, PCV Hand and PCV Headoffice entry areas
- Total Cash, Total PCV, Grand Total, Cash in Drawer and Variance
- Local saved records and CSV export
- Offline support after the first load

## Variance
All Total Cash = Total Cash + Other Cash / Adjustment. Grand Total = All Total Cash + Total PCV. Variance = Cash in Drawer - Grand Total. Positive means over; negative means short.

## Publish on GitHub Pages
Upload all files in this folder to your repository, then enable GitHub Pages from the repository Settings. Open the published site on your phone and choose Add to Home Screen / Install App.

Records are stored in the browser on the device. Export CSV regularly for backup.
